When *Spellcasters Chronicles* launched, I saw a chance to build something players could use right away. SpellcastersDB is an unofficial community database and deck builder.

The part I spent the most time on is **The Forge**, a deck builder that checks deck rules as you build and creates short links for sharing.

It also includes:

- **The Archive**: a searchable, filterable database of units, spells, titans and spellcasters.
- **Knowledge Tracker**: plan unlocks, track what you own and forecast daily progression, using the community API.
- **Guide Hub**: game mechanics, ranked tier ladders, class upgrades and progression.
- **The Trinity**: build teams of three decks with shared card-pool checks and short-link sharing.
- **Live updates**: balance changes come from a static JSON API, so the site doesn't need a full rebuild.
- **Themes and accessibility**: several colour themes, skip navigation, focus-trapped dialogs and ARIA labels.
