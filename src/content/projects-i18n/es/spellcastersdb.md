Cuando se lanzó *Spellcasters Chronicles*, vi la oportunidad de construir algo que los jugadores pudieran usar de inmediato. SpellcastersDB es una base de datos comunitaria no oficial y un creador de mazos.

La parte a la que dediqué más tiempo es **The Forge**, un creador de mazos que comprueba las reglas del mazo mientras lo construyes y genera enlaces cortos para compartir.

También incluye:

- **The Archive**: una base de datos con búsqueda y filtros de unidades, hechizos, titanes y lanzadores de conjuros.
- **Knowledge Tracker**: planifica desbloqueos, controla lo que posees y prevé la progresión diaria mediante la API comunitaria.
- **Guide Hub**: mecánicas de juego, clasificaciones por rangos, mejoras de clase y progresión.
- **The Trinity**: construye equipos de tres mazos con comprobación de cartas compartidas y enlaces cortos para compartir.
- **Actualizaciones en directo**: los cambios de equilibrio proceden de una API JSON estática, por lo que el sitio no necesita una reconstrucción completa.
- **Temas y accesibilidad**: varios temas de color, navegación de salto, diálogos con foco retenido y etiquetas ARIA.
