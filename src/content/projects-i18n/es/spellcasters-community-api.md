Primero construí la Spellcasters Community API para alimentar SpellcastersDB y luego la separé para que cualquiera en la comunidad pudiera utilizar los mismos datos.

Son datos JSON gratuitos y de código abierto que abarcan héroes, unidades, hechizos, titanes, consumibles, mejoras e infusiones, servido como archivos estáticos desde GitHub Pages. No requiere claves ni cuentas. Cualquiera puede enviar correcciones y nuevos datos a través del repositorio.
