This site is a set of static files. It has no accounts, no database and no server-side code. It sends strict security headers, and those headers are checked by automated tests.

## Reporting a problem

If you find a security issue, please email [security@terribleturtles.dev](mailto:security@terribleturtles.dev). Contact details are also published in [security.txt](/.well-known/security.txt).

My projects on other subdomains and sites are separate. Reports about them are welcome at the same address.
